# Магазин мебели

Описание
--------
Этот проект представляет собой веб-сайт для магазина мебели. Сайт позволяет пользователям просматривать каталог товаров, искать необходимые товары и добавлять их в корзину.

Технологии
-----------
- HTML
- CSS
- JavaScript (если используется)
- Google Fonts (Montserrat, Poppins)

Установка и запуск
------------------
1. Клонируйте репозиторий на свой локальный компьютер.
2. Откройте файл `index.html` в вашем веб-браузере.

Использование
-------------
- Используйте панель навигации для перехода между разделами сайта.
- Введите запрос в поле поиска, чтобы найти нужные товары.
- Добавьте товары в корзину для последующей покупки.
